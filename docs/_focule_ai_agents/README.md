# Focule AI Agents Directory

This directory contains specialized AI personas designed to assist with the development and maintenance of the Focule video transcription application. Each persona is crafted to address specific aspects of the codebase and provide expert guidance for complex challenges.

- Real-time performance monitoring

#### [AI Integration Architect](./AI_INTEGRATION_ARCHITECT.md)

#### [Error Recovery Specialist](./ERROR_RECOVERY_SPECIALIST.md)

## 🚀 How to Use These Personas

### **Starting a New Chat**
1. Copy the prompt from the desired persona file
2. Start a new chat with your AI assistant
3. Paste the entire prompt block (including the triple backticks)
4. Begin your specific task or question

### **Example Usage**
```bash
# For performance optimization
"I need help optimizing the video processing performance in my Electron app. The UI freezes during long transcription operations."

# For AI integration
"I want to improve the Whisper transcription accuracy and add better model selection logic."

# For error handling
"The application crashes when FFmpeg fails. I need better error recovery."

# For code quality
"I have duplicate error handling code throughout my components. Can you help consolidate it?"
```

## 📋 Best Practices

### **Before Using a Persona**
1. **Identify the Problem**: Clearly define what you're trying to solve
2. **Gather Context**: Collect relevant code snippets and error messages
3. **Choose the Right Persona**: Select the specialist that best matches your needs
4. **Provide Context**: Give the AI enough information about your project structure

### **During the Conversation**
1. **Be Specific**: Provide concrete examples and code snippets
2. **Ask Follow-up Questions**: Don't hesitate to ask for clarification
3. **Iterate**: Work through solutions step by step
4. **Test Suggestions**: Validate the AI's recommendations in your codebase

### **After the Session**
1. **Review Changes**: Ensure all modifications are correct
2. **Test Thoroughly**: Verify that the solution works as expected
3. **Document Changes**: Keep track of what was modified and why
4. **Share Feedback**: Note which personas worked best for different types of problems
